# Mapeia IA

Aplicação web em português para criação e organização de mapas mentais e materiais visuais de estudo.

## Desenvolvimento
- Node.js 20+
- `npm install`
- `npm run dev`

## Build
- `npm run build`

## Estado atual
Este primeiro MVP contém dashboard, fluxo de criação de rascunhos, editor visual básico, biblioteca local, modelos e configurações. Os materiais desta etapa são armazenados no navegador via localStorage.

## Integrações ainda necessárias
- Provedor de IA no backend para geração real de mapas, resumos e flashcards.
- Processamento seguro de PDF.
- Autenticação e banco de dados com isolamento por usuário.
- Gateway de pagamentos para planos e assinaturas.
- Exportação PDF/PNG; por enquanto o editor permite exportar SVG.

Nenhuma geração por IA, cobrança ou autenticação é simulada como funcional.
